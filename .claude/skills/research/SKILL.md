# Research

Decompose the question into verifiable subquestions.

Use this evidence order:
1. official documentation/specification
2. official source repositories
3. authoritative technical publications
4. reputable engineering sources
5. community reports for operational experience

For each important claim record:
- claim
- source
- source type
- date if available
- authority
- confidence
- implication

Actively search for contradictions.

Write durable artifacts to `.ai/research/active/` and `.ai/evidence/`.

End with:
- recommendation
- alternatives
- risks
- unknowns
- validation steps
