# New Project Workflow

## Gate 1 — Intent
Define:
- problem
- users
- business objective
- non-goals
- constraints
- success criteria

## Gate 2 — Discovery
Inspect repository/tooling or, for an empty repository, establish the minimum project foundation.

## Gate 3 — Research
Research unknown technologies and material decisions.

## Gate 4 — Architecture
Produce ADRs and architecture documentation.

## Gate 5 — Plan
Create implementation plan and acceptance criteria.

## Gate 6 — Build
Implement incrementally.

## Gate 7 — Verify
Run tests, static checks, build, and runtime validation.

## Gate 8 — Review
Review diff, security, architecture, and evidence.

## Gate 9 — Ship
Only after required human approval.
