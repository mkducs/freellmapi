# New Feature Workflow

Input:
- feature description
- relevant product requirements
- constraints

Artifacts:
- discovery report
- research report if required
- ADR if architectural
- implementation plan
- verification report

Required sequence:

1. Discover.
2. Identify unknowns.
3. Research unknowns.
4. Decide architecture.
5. Define acceptance criteria.
6. Plan.
7. Implement.
8. Verify.
9. Review.
10. Document.
