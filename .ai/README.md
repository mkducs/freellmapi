# Persistent AI Workspace

This directory is the durable memory and evidence layer for the engineering workflow.

Do not place secrets, tokens, credentials, customer PII, or production dumps here.

## Directories

- `context/` — stable project facts
- `research/` — active and completed investigations
- `evidence/` — claim/source ledger
- `architecture/` — system architecture
- `decisions/` — ADRs
- `plans/` — active/completed implementation plans
- `verification/` — test and verification evidence
- `templates/` — reusable artifact templates
- `logs/` — optional local workflow logs
