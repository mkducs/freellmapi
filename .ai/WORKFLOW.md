# Workflow State Contract

The active task should always have a recognizable state:

INTAKE
DISCOVERY
RESEARCH
SYNTHESIS
ARCHITECTURE
PLAN
IMPLEMENTATION
VERIFICATION
REVIEW
APPROVED
SHIPPED

Use `.ai/research/`, `.ai/decisions/`, `.ai/plans/`, and `.ai/verification/`
to make the state and evidence durable.

A phase is complete only when its required artifact/evidence exists.
